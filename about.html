NOTAM MAP View について

アプリの概要・目的

「NOTAM MAP View」は、パイロット、航空従事者、および航空ファンの皆様に向けて、リアルタイムな航空情報（NOTAM：Notice to Air Missions）を地図上で視覚的かつ直感的に確認できるように開発されたWebマップアプリケーションです。
テキストだけで配信される難解なNOTAMの座標や対象エリアを解析し、ポリゴンやラインとして地図上に描画することで、飛行計画の立案や空域の安全確認をサポートします。

主な機能と使い方

  • ICAOコード検索: 画面上部の検索バーに空港やFIRのICAOコード（例: RJTT, RJAA, EGTTなど）を入力して「Search」ボタンを押すことで、その地域の最新NOTAMを取得し、対象空域やルートを地図上にビジュアル表示します。
  • 取得日時（Latest Data）の確認: 画面右上には、バックエンドサーバーがFAAから約4分おきに自動取得しているデータの実際の最終更新日時が表示され、常に情報の鮮度を確認できます。
  • キーワード・日付フィルター: 取得したNOTAMリストから特定のキーワード（RWY, TWY, ILSなど）や有効期間で絞り込みを行ったり、リストを並び替えて必要な情報を素早く抽出できます。
  • 地図のフルスクリーン表示: 画面左上の「⛶ 画面を広く」ボタンを押すことで、メニューやリストを非表示にし、広域の空域制限を俯瞰して確認できます。

実際のフライトプランの作成や航空機の運航にあたっては、必ず公式の航空情報（AIP, AIS Japan, FAA等）の原本を併せてご確認ください。

About NOTAM MAP View

Overview & Purpose

"NOTAM MAP View" is a web map application designed for pilots, aviation professionals, and aviation enthusiasts to visually and intuitively check real-time NOTAMs (Notice to Air Missions) on a map.
By parsing complex NOTAM coordinates and affected areas, it draws polygons, lines, and circles on the map, supporting flight planning and airspace safety checks.

Features & Usage

  • ICAO Code Search: Enter ICAO codes (e.g., RJTT, KLAX, EGTT) in the search bar to fetch the latest NOTAMs. The app visualizes restricted airspaces and routes.
  • Latest Data Timestamp: The badge at the top right displays the actual last-modified timestamp of the backend data, which is automatically updated from the FAA approximately every 4 minutes.
  • Filters & Sorting: Narrow down NOTAMs using keywords (RWY, TWY, ILS, etc.) or effective dates, and easily sort the list to find what you need.
  • Fullscreen Map: Click the "Expand Map" button to hide the lists and filters, maximizing your map viewing area for better situational awareness.
